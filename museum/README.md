# 根在侨乡 · 云端博物馆漫游

> 一座馆，一条动线，十五站。

按江门「中国侨都华侨华人博物馆」的参观动线做的网页解谜游戏：从正门进馆，穿过大厅、序厅，一路走到「远赴重洋」「拼搏海外」「融通中外」，用十五个互动关卡把展板和文物"玩"一遍。整体是密室逃脱式的：暗厅、展签、机关、传送门，一关一关往下走。

纯静态网页，无需服务器、无需安装，上传到任意静态空间即可发布。

---

## 零、怎么发布给别人

完整的发布步骤见项目根目录的 **《发布说明.md》**。最短路径：

1. 把 **整个 `根在侨乡_博物馆漫游` 文件夹**上传到任意静态托管；
2. 推荐 Netlify Drop（拖进去即可）或 GitHub Pages；
3. 部署到 HTTPS 后，可用手机“添加到主屏幕”，首次打开后断网也能玩（PWA）。

> 注意：不要只传 `index.html`，`assets/` 必须一起上传。

---

## 一、怎么打开

**方式一（最简单）**：双击 `index.html`，用 Chrome / Edge / Safari 打开。

**方式二（推荐）**：在本文件夹内启动静态服务：

```bash
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://127.0.0.1:8000/`。

> 直接双击打开时，个别浏览器会限制本地存档（游戏会自动降级，不影响通关）。

---

## 二、怎么发布到网上

纯静态站点，整包上传即可，无后端、无构建：

| 平台 | 操作 |
| --- | --- |
| 虚拟主机 / 服务器 | 把本文件夹全部文件上传到网站根目录或子目录 |
| GitHub Pages | 上传仓库 → Settings → Pages → 选择分支根目录 |
| Netlify / Vercel / Cloudflare Pages | 拖拽文件夹上传，无构建命令 |
| 微信内嵌 | 用 web-view 指向部署后的 HTTPS 地址 |

保持 `index.html` 与 `assets/` 同级；建议启用 HTTPS。

## 三、底部控制条（每一关都有）

屏幕底部常驻三个按钮：

- **重玩本关**：把当前关卡重置到初始状态（地图关会清空已找到的地点）。
- **上一关**：随时可以退回上一关。
- **下一关**：本关通关后才会亮起；没通关时显示「未通关」，点击会提示"请先完成本关，才能进入下一关"。

## 七、技术说明

- 纯原生 HTML + CSS + JavaScript，零框架、零外部依赖，可离线运行。
- 两个 Canvas 小游戏（航行、躲避落石）+ 一个 SVG 动态线路图 + 一个翻牌配对。
- 拖拽同时支持「拖」和「点选」，手机与桌面都能玩；落石关卡用左右按钮操作。
- 音效由 Web Audio 实时合成（无音频文件），右上角可关闭。
- 适配 iOS 安全区、`prefers-reduced-motion`；建议竖屏游玩。

## 九、视觉主题（v4 · 侨文化古风）

- 宣纸为底、墨为骨、朱砂为印、铜金为饰；全站只用一种画框（1px 铜金外框 + 内缩 6px 的 1px 内线）。
- 照片统一做暖墨处理（sepia 10% + 对比 1.05），并裱在宣纸上：7px 纸边、下方金线 + 宋体展签。
- 标题宋体、说明楷体；章节小标题前加 7px 菱形朱标；首页右上角固定「僑鄉」竖章。
- 背景保留深墨色以突出场景，但压低遮罩浓度，让照片更清晰。

## 十、展板门框（v5 · 第一/第二部分与序厅统一）

三个叙事屏共用一套「展板门框」版式，对应馆内原件：

- 门头：SVG 绘制的碉楼城垛（含四个拱窗），颜色随章节变化（第一部分青绿、第二部分橙红、序厅铜金）。
- 左侧竖条：章节号（第一部分 / CHAPTER ONE）竖排。
- 中间竖排大标题：远征重洋 / 拼搏海外 / 侨乡入口。
- 右侧蓝光展板：英文标题、中文正文、英文正文，底部一张线描（帆船 / 铁路）。
- 序厅入口把展板正文换成黑洞，标题与门头沿用同一套，点击黑洞推镜进厅。
- 进入时展板由下浮入，离开时放大淡出，像穿过门框。

## 十一、长文弹窗（v6 · 设计参考自两个 Phaser 小游戏）

世界华侨分布图上的每个点位卡片，右下角多了一个「读长文 ›」按钮：

- 点开后是一张宣纸长文卡：朱砂题头、宋体标题、首字下沉、可滚动正文、底部「全文约 N 字」与关闭按钮。
- 弹窗层级 9999，点遮罩空白、按 Esc、点关闭都能关；正文超出高度时出现铜金→朱砂渐变滚动条。
- 八篇长文对应八个点位：加拿大、美国、秘鲁、英国、南非、马来亚、印尼、澳大利亚，每篇 340–380 字。
- 入口只加在点位卡片上，关卡流程、判定、存档都不变；卡片左侧加了一条朱砂→铜金的细竖条（参考调度游戏的任务卡）。

## 十四、PWA / 离线

- `manifest.json`：应用名、图标、独立窗口显示；
- `sw.js`：预缓存核心文件，照片首次访问后自动缓存，断网可玩；
- 图标：`assets/img/icon-192.png`、`icon-512.png`、`apple-touch-icon.png`；
- 更新版本时把 `sw.js` 里的 `VERSION` 改一位即可强制刷新缓存。
