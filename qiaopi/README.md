# 侨批归途 · 云端侨乡剧情解谜

> 一封侨批，三代人的南洋与故乡。

这是《侨文化云端剧情文创——乔盛文具创新文旅产品策划方案》中"产品 1：云端线上剧情解谜系统"的可玩成品。纯静态网页，无需服务器、无需安装，上传到任意静态空间即可对外发布。

---

## 一、怎么打开

**方式一（最简单）**：双击 `index.html`，用 Chrome / Edge / Safari 打开即可游玩。

**方式二（推荐，本地预览）**：在本文件夹内启动一个静态服务，再访问 `http://127.0.0.1:8000/`

```bash
# 有 Python 时
python -m http.server 8000

# 有 Node 时
npx serve .
```

> 建议用方式二：`file://` 直接打开时，个别浏览器会限制本地存档与"生成归途卡"的图片导出（游戏会自动降级，不影响通关）。

---

## 二、怎么发布到网上

本作是**纯静态网站**，把整个文件夹原样上传即可，无需数据库、无需后端：

| 平台 | 操作 |
| --- | --- |
| 任意虚拟主机 / 服务器 | 把 `侨批归途_网页游戏` 里的全部文件上传到网站根目录或子目录 |
| GitHub Pages | 新建仓库 → 上传全部文件 → Settings → Pages → 选择分支根目录 |
| Netlify / Vercel / Cloudflare Pages | 直接拖拽文件夹上传，或连接仓库，无构建命令、无输出目录 |
| 微信 / 小程序内嵌 | 用 web-view 指向部署好的 HTTPS 地址 |

部署后访问 `https://你的域名/`（若上传到子目录，则为 `https://你的域名/子目录/`）即可。

**注意**：
- 保持目录结构不变（`index.html` 与 `assets/` 同级）。
- 建议启用 HTTPS，微信内打开、剪贴板等功能在 HTTPS 下才正常。
- 文件名与路径均为英文（仅文件夹名是中文），可自行改名，不影响运行。

## 四、内容与玩法

- **序章 + 四篇**：序章「旧木箱的来信」→ 出海闯荡 → 南洋打拼 → 侨批寄思 → 归乡兴家，主角陈启山 1901 年从新宁县（今台山）广海湾出洋，1935 年回乡建碉楼。
- **六道谜题**：
  1. 密信译码 —— 用《千字文》头十字换算侨批数码，打开木箱四字锁；
  1b. 船票与契约 —— 用票号、票价、月钱算「做几个月才抵清船资」，答对才出海；
  2. 侨汇账簿 —— 补全三处被涂掉的数字，让账簿平账；
  3. 家书六句 —— 按侨批格式排出六句话，再以火漆封印；
  4. 碉楼图样 —— 把"燕子窝、拱券门额、卷草女儿墙、铁窗百叶"安到正确位置；
  5. 族谱寻根 —— 从抬头与落款判断四封旧批的收信人。
- **抉择与三结局**：每次抉择累加"亲情 / 开拓 / 家国"三项心境，分别通向 **A 归乡筑梦 / B 南洋扎根 / C 漂泊无归**；全程不用提示、一次答对，可解锁隐藏**真结局「根在侨乡」**。
- **第三篇新增两场**：回批（家乡来信）与暗语（"山高水长"即病重），对应馆藏侨批里最动人的两类材料。
- **收集要素**：10 张侨史记忆卡、40 张侨乡影集、6 则侨史小课堂、番外「四季盲盒」四款纹样。
- **其他**：自动存档（localStorage）、音效开关、响应式（手机 / 平板 / 桌面）、键盘 Enter 继续、可生成并下载"归途卡"分享图。

通关约 15 分钟。

## 五、照片说明

`assets/img/` 中的 40 张照片，均从团队江门五邑实地调研的 335 张原片中筛选，**只保留建筑、器物、侨批文书、展陈与街景，未使用任何含真人的照片**；人物塑像场景也一律未采用。照片已统一压缩为长边 1000–1500 px、渐进式 JPEG，兼顾清晰度与加载速度。

影集页与"关于"页均已注明素材来源与用途。

## 六、二次修改

- **改文案 / 剧情 / 谜题**：编辑 `assets/js/data.js`。剧情是 `CHAPTERS`，谜题在 `PUZZLES`，卡片在 `CARDS`，影集在 `ALBUM`，结局在 `ENDINGS`。谜题答案与数据写在同一处，改完即生效。
- **改配色 / 字体 / 版式**：编辑 `assets/css/style.css` 顶部的 CSS 变量（`--red`、`--gold`、`--paper` 等）。
- **换照片**：把新图放进 `assets/img/`，在 `data.js` 中把对应的文件名（不含 `.jpg`）替换掉即可；建议长边不超过 1600 px、单张 300 KB 以内。
- **接入付费解锁**：当前"完整结局"默认免费开放，便于演示。若需接入付费，可在 `finishChapter()` 进入第四幕前加一道校验（如登录态 / 订单号），通过后再调用 `startChapter(3)`。

## 七、技术说明

- 纯原生 HTML + CSS + JavaScript，**零外部依赖、零框架、可离线运行**。
- 存档键名 `qiaopi_gui_tu_v1`，清除浏览器缓存会重置进度。

- 已适配 iOS 安全区、`prefers-reduced-motion`（减少动效）、键盘操作。
- 兼容 Chrome / Edge / Safari / Firefox 近两年版本。

## 十、交互修复与番外

- **防连点**：`nextStep()` 加了 320ms 节流，连续点“开始/继续”不会一次跳两步、直接闪到下一个界面。
- **底部栏不再拦截点击**：`.continue-bar` 背景设为 `pointer-events: none`，只有按钮本身可点，避免点在栏上误触“继续”。
- **番外 · 四季盲盒**：枢纽页新增入口，弹出春（木棉与批封）、夏（南洋纹样）、秋（花鸟批封）、冬（碉楼灯火）四款纹样说明。

### 2. 每篇一封「旧信」

每篇开场多了一个「读一封旧信」按钮，不影响主线流程，只是可选阅读：

- 第一篇：父亲从南洋寄回的信（叮嘱船资、找阿四叔）
- 第二篇：母亲托人写的回批（还债、买田、弟弟入塾）
- 第三篇：同乡阿坤托写的批（借钱、勿告我母）
- 第四篇：族谱里夹着的一页（启山公小传）

四封信从四个视角补足了主角之外的人：父亲、母亲、同乡、后人。

## 十二、随机化、难度与文具联动（v1.2）

### 背景音乐
- Web Audio 实时合成，无音频文件：低音铺底 + 五声音阶随机拨弦，音量很轻。
- 首次点击后淡入；右上角喇叭可一键关闭（与音效共用一个开关）。

### 谜题随机化
| 谜题 | 每局变化 |
| --- | --- |
| 密信译码 | 50 字库里随机取 10 个，随机配 0-9；密码每局不同，题面记号字随之变化 |
| 船票与契约 | 三套题随机：①工钱抵船资 ②票号后两位＋日期 ③行李限重 |
| 侨汇账簿 | 每月收入/寄回/开销随机生成，结余由公式推出，再随机挖三个空 |
| 族谱寻根 | 四格之外多一封「表弟」写的干扰信，且不再显示寄信人，只能靠抬头与落款判断 |

### 难度
- 密信不再有固定答案，必须真的查表换算；
- 账簿要按月推，不能套固定数字；
- 族谱要排除干扰信，四个称谓都得对上。

### 解谜文具联动
每个谜题底部新增「文 具」按钮，点开告诉玩家这一关该用套装里的哪件：

- 密信 → **铜牌对照表**
- 船票 → **钢尺与算纸**
- 账簿 → **放大镜**（看墨渍下的凹痕）
- 家书 → **信纸与火漆**
- 碉楼 → **构件卡**
- 族谱 → **放大镜与族谱页**
